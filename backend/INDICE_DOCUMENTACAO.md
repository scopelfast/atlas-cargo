### Adicionar Nova Documentação

1. Siga o padrão definido em [ESTRUTURA_DOCUMENTACAO.md](ESTRUTURA_DOCUMENTACAO.md)
2. Use Markdown
3. Inclua índice navegável
4. Adicione exemplos práticos
5. Inclua seção de troubleshooting
6. Atualize este índice

### Atualizar Documentação Existente

1. Mantenha o formato original
2. Atualize a data de última atualização
3. Incremente a versão se necessário
4. Documente mudanças significativas
