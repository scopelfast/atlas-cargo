Ajuda - Mapa de Viagem

📋 Sobre o Módulo

O módulo Mapa de Viagem permite visualizar a última posição de cada placa em um mapa interativo em tempo real.

🗺️ Funcionalidades

  • Visualização da última posição de cada placa no mapa
  • Filtros idênticos ao módulo "Gerenciar Viagens"
  • Informações detalhadas ao clicar em cada marcador
  • Atualização em tempo real das posições
  • Centralização automática do mapa para mostrar todos os veículos

🔍 Como Usar

  • Use os filtros acima para selecionar as viagens que deseja visualizar
  • Clique em Filtrar para carregar as posições no mapa
  • Clique nos marcadores azuis para ver informações detalhadas de cada veículo
  • Use o botão Centralizar para ajustar o zoom automaticamente
  • Use o botão Atualizar para recarregar as posições

💡 Dicas

  • Os marcadores azuis representam a última posição de cada placa
  • Cada marcador mostra: Viagem, Placa, Motorista, Roteiro e Data/Hora da Posição
  • Use os filtros para focar em viagens específicas
  • O mapa se ajusta automaticamente para mostrar todos os veículos filtrados
