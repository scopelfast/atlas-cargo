Em desenvolvimento

Módulo em construção

Este módulo exibirá o ranking de motoristas com base em uma pontuação de desempenho (Driver Score). A pontuação será calculada a partir dos alertas gerados pelo sistema durante as viagens.

Cada motorista receberá uma nota de 0 a 100. Quanto maior a nota, melhor o desempenho (menos ocorrências de alertas no período). Os critérios e pesos por tipo de alerta serão configuráveis.

O que virá neste módulo

  • Ranking ordenado por pontuação (período selecionável: mês, trimestre)
  • Driver Score por motorista com detalhamento por tipo de alerta
  • Pesos configuráveis por tipo (ex.: excesso de velocidade, atraso, offline, desvio de rota)
  • Uso dos dados da tabela de Alertas já gerados pelo sistema

Documento de apoio: Alertas → RANKING_ALERTAS_PONTUACAO.md (critérios e boas práticas).
