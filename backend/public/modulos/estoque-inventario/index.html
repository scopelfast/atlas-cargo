Resumo de ajustes (por produto)

Sistema = saldo atual do ledger (mesma base da Movimentação). Contado = soma de todas as linhas do mesmo código (cada validade/lote contada separadamente). Se o snapshot da linha divergir do ledger, aparece aviso — o encerramento usa o ledger. Todo SKU contado entra nesta tabela — ajuste 0 significa posição OK (não gera movimento no encerramento).

Gerar lista de inventário cíclico

Escolha um critério para selecionar os SKUs do ciclo. O sistema cria um inventário CICLICO já com as linhas pré-populadas (snapshot por SKU). Só os itens listados serão ajustados — saldo do restante do armazém é preservado.

Filtros de produto — escolha no combo (cadastro WMS)

ABC (giro) Top N SKUs com maior giro na janela (princípio de Pareto).
Vencimento próximo FEFO: SKUs com validade até X dias. Reduz risco de perda.
Não contados há mais tempo SKUs sem contagem recente. Garante cobertura mensal.
Mais movimentados Top N por volume de entradas + saídas na janela.
Aleatório (amostragem) Sorteio estatístico — útil para auditoria sem viés.
Por conservação Todos os SKUs do tipo informado (use o filtro Conservação).

Dividir lote/validade

Linha de origem: —

Cria uma nova linha do mesmo SKU com lote/validade diferentes. Útil quando você descobre múltiplas validades reais em campo e o snapshot tinha uma validade genérica. Pelo menos um campo (lote ou validade) precisa ser diferente da linha original.

Adicionar SKU à contagem

Para produto encontrado em campo que não estava na lista. O SKU precisa estar cadastrado no dono deste inventário.

Transferência entre donos

Move saldo de um SKU de um dono para outro. Gera 2 movimentos no ledger de estoque (saída na origem + entrada no destino) e um documento auditável. Se o SKU não existe no destino, o sistema pergunta antes se deve cadastrar automaticamente copiando o cadastro da origem.
