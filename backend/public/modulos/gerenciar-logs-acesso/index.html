Ajuda - Logs de Acesso

📋 Sobre o Módulo

O módulo Logs de Acesso permite visualizar e analisar todas as atividades dos usuários no sistema, incluindo acessos, tempo logado, módulos acessados e ações realizadas.

🔍 Filtros

  • Data Início/Fim: Filtre os logs por período específico
  • Operador: Filtre por login do usuário específico
  • Clique em "Filtrar" para aplicar os filtros ou "Limpar" para resetar

📊 Resumo

  • Visualize estatísticas gerais de acessos
  • Veja o tempo total logado de todos os usuários
  • Confira quantos módulos foram acessados
  • Analise estatísticas por operador
  • Veja os módulos mais acessados

💡 Dicas

  • Use os filtros para análises específicas por período ou usuário
  • O resumo oferece uma visão geral rápida das atividades
  • Os detalhes permitem análise aprofundada de cada acesso
