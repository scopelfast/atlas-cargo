Escopo do painel

Números abaixo são do tenant selecionado (não da instalação padrão do login). Conexão = motorista paga esse agenciador. Uso = esse agenciador paga a Atlas. Para o consolidado (quem deve à Atlas), escolha Todos os tenants (painel Atlas).

Faturamento conexão em aberto

Quem me deve (uso da plataforma)

Cobranças abertas dos agenciadores → Atlas (SaaS). Não inclui conexão de motorista. Clique no tenant para operar aquele cliente.

Quem cobra quem neste tenant

A · Conexão

Motorista paga o agenciador desta instalação, quando a torre confirma o motorista na carga.

Configure aqui se este tenant é o agenciador que opera as ofertas.

B · Uso da plataforma

O agenciador (este tenant) paga a Atlas pelo uso do sistema — fechamento mensal na aba Fechamento de uso.

Cobrança SaaS. Só a Atlas (instalação padrão) define preço, regra ligada e inadimplência.

Cada tenant tem o próprio contrato. O agenciador configura a Conexão (A) no tenant dele; o Uso (B) é tabela comercial da Atlas — o tenant só consulta.

Segurança: neste tenant você edita só a Conexão (A). Uso da plataforma, regra financeira e inadimplência são definidos pela Atlas no painel padrão (operar agente).

Publicar nova versão

Versões antigas não se editam (congelam o histórico). Para mudar preço ou regra, publique uma nova versão. Use Ver no histórico e Usar como base para copiar a configuração.
