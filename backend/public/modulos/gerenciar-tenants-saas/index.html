Composição do plano

Escolha o plano, ajuste limites (cada um com o seu guardar) e marque os módulos. Use Salvar plano para gravar os módulos de uma vez.

Como usar este limite

Referência na lista de clientes (uso/lim). O cadastro de utilizadores ativos não é bloqueado por este número. O controlo de acessos simultâneos ao painel é o limite de sessões ao lado.

Como contam as sessões

Conta sessões abertas na janela do token (até o utilizador sair com Sair). Se alterar a duração do JWT, alinhe TOWER_SESSION_TTL_HOURS no .env.
