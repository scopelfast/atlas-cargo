1. Sobre o Sistema

O Sistema DivulgaCarga é uma aplicação web completa para gestão de transportes, desenvolvida para gerenciar cadastros, equipamentos, viagens, empresas, filiais e demais aspectos operacionais do negócio de transporte de cargas.

Funcionalidades Principais

  • Gestão completa de cadastros gerais (clientes, fornecedores, transportadores, motoristas)
  • Controle de equipamentos (marcas, tipos, modelos, grupos, classes de frota)
  • Gerenciamento de viagens e roteiros
  • Cadastro de empresas e filiais
  • Gestão de cidades com integração IBGE
  • Sistema de Grid com edição inline em todos os módulos
  • Soft delete/reativação em todos os módulos
  • Filtros avançados e busca
  • Sistema de mensagens toast profissional (vermelho para erro, verde para sucesso)
  • Validações e máscaras (CPF/CNPJ, CEP, Celular) com zero-padding
  • Integração WhatsApp no Grid de Cadastros
  • Sistema de Convocações: Identificação de motoristas compatíveis, envio via WhatsApp, gerenciamento de respostas
  • Sistema de Geolocalização: Captura automática da localização do motorista, indicadores visuais, visualização no mapa
  • Links do WhatsApp: Números de celular clicáveis abrem WhatsApp diretamente
  • Relatório de Convocações: Relatório completo com estatísticas, gráficos e filtros avançados
  • Interface responsiva e moderna
💡 Nota: O sistema utiliza soft delete (desativação) em vez de exclusão física, mantendo o histórico completo dos dados.

2. Arquitetura do Sistema

2.1. Arquitetura Geral

O sistema segue uma arquitetura MVC (Model-View-Controller) com separação clara entre frontend e backend:

🎨 Frontend

  • HTML5 + CSS3
  • JavaScript ES6+ (Vanilla)
  • Componentes reutilizáveis
  • SPA (Single Page Application)
  • Responsive Design

⚙️ Backend

  • Node.js + Express.js
  • MSSQL (SQL Server)
  • RESTful API
  • JWT Authentication
  • Helmet Security

    ↓ (HTTP Request)

    ↓ (SQL Query)
Database (SQL Server)

2.3. Estrutura de Módulos

Cada módulo do sistema segue uma estrutura padronizada:

Uso: Dados de municípios brasileiros

Uso: Geocodificação e reverse geocoding

Endpoints:

  • https://nominatim.openstreetmap.org/search - Geocodificação (endereço → coordenadas)
  • https://nominatim.openstreetmap.org/reverse - Reverse geocoding (coordenadas → endereço)

Aplicação: Busca de coordenadas, preenchimento automático de endereços, seleção no mapa

Uso: Cálculo de rotas e distâncias reais

Endpoint: https://router.project-osrm.org/route/v1/driving/

Aplicação: Cálculo de distâncias entre pontos usando rotas reais de estradas

Formato: /route/v1/driving/{lon1},{lat1};{lon2},{lat2}?overview=full&geometries=geojson

Usado em: Roteiros, Visualização de localização do motorista, Cálculo de distância até ponto de carregamento

📱 WhatsApp Web API

Uso: Links diretos para abrir conversa no WhatsApp

Formato: https://wa.me/5511999999999 (com código do país)

Aplicação: Números de celular clicáveis em Relatório de Convocações e Gerenciar Convocações

Características: Limpeza automática do número, adição de código do país, validação

🌐 Geolocation API (Browser)

Uso: Captura de localização do motorista (latitude/longitude)

API: navigator.geolocation.getCurrentPosition()

Aplicação: Captura automática quando motorista acessa/responde convocação

Recursos: Modal bloqueante se permissão negada, botão manual de envio

📦 GitHub (kelvins/Municipios-Brasileiros)

5.8.1. Sistema de Cálculo de Distâncias

OSRM (Open Source Routing Machine) - Prioritário:

  • Usa rotas reais de estradas
  • Calcula distância considerando o caminho real
  • Suporta múltiplos pontos intermediários
  • Retorna geometria da rota para visualização no mapa
  • API: https://router.project-osrm.org/route/v1/driving/

Haversine (Fallback):

  • Cálculo de distância em linha reta
  • Usado quando OSRM não está disponível
  • Fórmula matemática precisa para distâncias curtas

Implementação:

  • Cálculo automático ao salvar ponto
  • Recalculo automático ao editar roteiro
  • Atualização em tempo real no Grid
  • Exibição de distância acumulada desde a origem

OSRM (Prioritário):

// Exemplo de uso do OSRM
const osrmUrl = `https://router.project-osrm.org/route/v1/driving/${lon1},${lat1};${lon2},${lat2}?overview=full&geometries=geojson`;

Haversine (Fallback):

function calcularDistanciaHaversine(lat1, lon1, lat2, lon2) {
  const R = 6371; // Raio da Terra em km
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLon = (lon2 - lon1) * Math.PI / 180;
  const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
    Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) *
    Math.sin(dLon/2) * Math.sin(dLon/2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  return R * c;
}

Resposta: NÃO! Ninguém precisa instalar ou configurar nada nas máquinas. Basta acessar pelo navegador. A configuração é feita apenas no servidor.
