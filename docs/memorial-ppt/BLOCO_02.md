# Bloco 2 — Pilares

## Quatro pilares

| Pilar | Entrega |
|-------|---------|
| **Gestão** | Empresas, filiais, cadastro geral, frota (marcas, grupos, tipos, modelos, classes, equipamentos). |
| **Operação** | Viagens, situações/tipos de viagem, roteiros georreferenciados, mapa de viagem, relatório de convocações. |
| **Campo** | App motorista: login, convocações, cargas, viagens, GPS, macros/ocorrências, POD, notificações. |
| **Confiança** | Chat torre–motorista, alertas, SOS, ranking/reputação, logs de acesso, JWT, dark mode, PT/ES. |

## Stack (slide opcional)

Node.js, Express, PostgreSQL, JWT, Socket.io. Web modular + motorista em `/motorista`.
