# Memorial PPT — uso em blocos (limite ~2000 caracteres)

Seu editor limita o prompt (~2000 caracteres). Use **um arquivo por vez**, na ordem:

| Arquivo | Conteúdo |
|---------|-----------|
| `BLOCO_01.md` | Título, tagline, o que é |
| `BLOCO_02.md` | Pilares (tabela resumida) |
| `BLOCO_03.md` | Destaques + público |
| `BLOCO_04.md` | Roteiro de slides |
| `BLOCO_05.md` | Prompts IA (imagens), parte 1 |
| `BLOCO_06.md` | Prompts IA, parte 2 + frase final |

Cada `BLOCO_*.md` tem **menos de ~800 caracteres** (bem abaixo de 2000). Se o seu limite for ainda menor, copie **um parágrafo** por vez.
